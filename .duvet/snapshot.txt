  SECTION: [6. Aggregation](#aggregation)
    TEXT[!MUST,implementation,test]: The count recorded for a line MUST be the sum of the
    TEXT[!MUST,implementation,test]: counts of every `DA` record for that line in every
    TEXT[!MUST,implementation,test]: source-file block naming that file.
    TEXT[!MUST,implementation,test]: The sum MUST saturate at the maximum unsigned 64-bit
    TEXT[!MUST,implementation,test]: value instead of overflowing.
    TEXT[!MUST,implementation,test]: A line with no `DA` record MUST be absent from the parsed
    TEXT[!MUST,implementation,test]: coverage for its file.
    TEXT[!MUST,implementation,test]: The parsed coverage MUST contain no branch data.

  SECTION: [Property 1: Domain Exactness](#property-1-domain-exactness)
    TEXT[implication]: A line number appears in the aggregated output
    TEXT[implication]: if and only if
    TEXT[implication]: at least one `DA` record for that line
    TEXT[implication]: appears in the input record sequence.

  SECTION: [Property 2: Count Correctness](#property-2-count-correctness)
    TEXT[implication]: The count aggregated for a line
    TEXT[implication]: equals the sum of the counts of every input record
    TEXT[implication]: for that line,
    TEXT[implication]: saturated at the maximum unsigned 64-bit value.

  SECTION: [Property 3: Ordered Uniqueness](#property-3-ordered-uniqueness)
    TEXT[implication]: The aggregated output is strictly sorted by line number,
    TEXT[implication]: so each line appears exactly once.

  SECTION: [Property 4: Block-Structure Invariance](#property-4-block-structure-invariance)
    TEXT[implication]: Splitting a record sequence into consecutive blocks
    TEXT[implication]: and summing per block
    TEXT[implication]: yields the same per-line totals as
    TEXT[implication]: summing the whole sequence:
    TEXT[implication]: for all record sequences `a` and `b` and every line `L`,
    TEXT[implication]: `sum(a ++ b, L) = sum(a, L) + sum(b, L)`.

    TEXT[test]: A scope is a contiguous range of lines

    TEXT[!MUST,implementation,test]: A classifier MUST emit a balanced `ScopeOpen`/`ScopeClose` stream:
    TEXT[!MUST,implementation,test]: matching each `ScopeClose` against the most recent unmatched `ScopeOpen`,
    TEXT[!MUST,implementation,test]: no `ScopeClose` occurs with no open to match,
    TEXT[!MUST,implementation,test]: and no `ScopeOpen` is left unmatched at end of file.
    TEXT[!MUST,implementation,test]: When the stream is unbalanced,
    TEXT[!MUST,implementation,test]: the coverage model MUST NOT score annotations against the collapsed scope tree;
    TEXT[!MUST,implementation,test]: it MUST surface the file as a defeated classification and escalate
    TEXT[!MUST,implementation,test]: (see [Classifier Selection and Dispatch](#dispatch)).
